# AI决策与强度验证

AI离线运行，仅接收自己的手牌、公开场面、合法揭示的信息及合法动作。简单、普通、困难统一使用新版规划器与估值，仅主要阶段前瞻深度分别为1／2／4步。难度不改变评分、候选筛选、搜索宽度、采样数、随机平分处理、骰子、费用、次数限制或信息权限；简单不再额外随机放行或故意选差动作。

## 决策过程

1. 从脱敏观察构造两个独立信息集样本；未知手牌与牌序来自未见牌池，使用独立RNG。
2. 按阵营关系、实际P／GP支援资格、分支收益和上级安全筛选候选。通常保留64个粗选动作，再选少量根动作；大局面降低候选与节点预算。
3. 主要阶段简单／普通／困难最多搜索1／2／4步。三档均使用2个样本、最多128个搜索节点、常规宽度2和最多8个根候选；超过120／500个合法动作时统一收紧预算。每个动作都通过真实规则模块结算，交替响应与触发由同一引擎执行。根动作分配相近的预算，比较后续分支的期望收益；达到节点预算时可能提前停止。
4. 普通骰子在最终响应后枚举2d6的11种点数和，并按出现次数加权；成功、失败、受灾与摧毁都由引擎判定。固定骰按已知结果计算。等价后续状态合并；重掷和随机抽弃牌仍是信息集样本，不能将整个搜索称为完全精确的概率计算。
5. 主要阶段按结束回合后的局面比较，避免奖励到期却未利用的准备效果。战斗与反制窗口比较支援、阴谋、资源和放行后整场战斗的结果；不在每次响应后再搜索后续主要行动，待战斗完成后重新规划。

搜索是有限宽度和有限深度的启发式规划。它会预演当前战斗的对方响应，没有完整搜索对手下一整个回合，也不能保证找到最优策略。候选筛选、后续选择及隐藏信息样本仍可能判断失误。

## 估值重点

- **增强己方、削弱敌方**：团体数量、有效P／GP、控制槽和持续在场价值；敌方相应收益反向计分。夺取整支同时增加己方并减少敌方实力，摧毁则按实际离场与下属回手后的局面计算。
- **胜利进度**：同时考虑各项要求及最短板，接近达标时提高优先级。只在持有者一侧计入私密目标；不会读取对手真实目标牌。
- **防守与结构**：有效R、忠诚、位置、被动防御和上级路径薄弱环节；己方回合末保留的团体行动能防守，具有价值。这是风险启发式，不是准确的被夺取概率。
- **资源与手牌**：部署的资源按基础设施估值；空余资源位、备用手牌和未来可部署性影响库存价值。只可在主要阶段使用的资源行动，不因回合末留存标记而获得虚假收益。战斗资源按真正改变的结果及报废代价评估。

临时强化本身没有固定“出牌加分”；必须通过后续动作产生持续收益。相同规则适用于新的能力和阴谋，不另写一套卡牌结算。用于粗筛的既有卡牌启发式仍保留，最终选择由引擎预演修正。

## 性能与信息边界

搜索在线程独有的Agent、规则副本和RNG上执行，不接触场景、纹理、玩家设置或真实GameState。打开设置、查看战场、重开和退出会取消旧任务；取消后不能支付费用或向新对局提交命令。

模型的动作从合法列表取得后，可通过`GameState._act_generated`进入与`act`相同的派发、槽位修复和目标手牌清理，减少重复生成动作列表。观察中的根动作先在两个样本中验证。真实界面与基准比赛仍逐步调用`act`，检查合法性、守恒和真实RNG不被AI改变。

当前三档的配置、相关回归与6场逐局比对见[三档统一验证](ai_difficulty_current.json)；同种子主要行动序列和全阶段行动计数也均匹配原记录。

## 同种子输家替换与信息审计

补充实验先用种子1001–1050、相同派系和相同限制各跑一局旧困难对旧困难，确定原输家；再匹配原100局中“新困难坐在原输家席位”的那局。复用已有的新旧对局，未将这些结果再当作50场独立新样本计入76%的胜率，也未根据新AI是否获胜筛选种子或修改策略。

50局控制组都有明确胜负；替换输家后36胜14负，翻盘率72%，无平局、未结束或非法动作。完整逐组记录见[翻盘对照](ai_replacement_current.json)。

- 对所有50种子重放双方开局，核对手牌、牌序、场面、先后手、重随状态与真实RNG的开局SHA-256；两种替换席位均与旧对旧控制组一致。开局指纹只用于离线审计，从不提供给AI。
- 预先固定种子1001、1012、1050，交换席位共6场完整重跑。胜负、回合数、步骤数、各类行动次数、先后手和获胜原因均与原记录一致。
- `test_ai_fairness.gd`在普通／困难、主要阶段／战斗／反制窗口中改变真实隐藏手牌、牌序及真实RNG，验证观察、模型样本和同AI种子的决策不变，且思考不修改真实规则状态或共享卡牌定义。38项通过。
- 冻结基线的四份原始文件与旧Git提交逐字节核对，仅移除全局类名并改内部预加载路径；新旧共用同一规则。汇总器另外通过拒绝控制组混入、非法记录、混合版本、未完成分片及重复种子／席位的5项负例检查。

同种子固定的是起点和随机生成规则。策略分歧后，不同的抽牌、洗牌、骰子调用会消耗不同数量的随机数，因此不能声称后续每一场攻击都面对完全相同的骰点。72%也是这50个固定场景下的样本比例，不是对任意劣势局面的翻盘保证。

## 新困难AI的游戏风格

整体倾向于主动争夺场面，以持续实力和实际胜机决定投入。它仍会扩张和追求主牌条件，也更重视从敌方手里夺走整支团体的双向收益。

| 方面 | 决策倾向与边界 |
|---|---|
| 扩张节奏 | 比较自动接管、从手牌控制、抢夺与建设资源。适配派系、能补目标短板的团体更有吸引力；团体手牌收益递减，减少囤积却不部署。 |
| 进攻选点 | 同时看成功概率、目标实力和其下属分支。高收益抢夺可能优于单纯补一张手牌；摧毁按实际削弱及下属回手的结果计分，不只看目标印刷P。 |
| 支援与防守 | 查询真正可用的P／GP支援；比较付标记、弃牌和报废资源后的整场战斗。保留可在敌方回合防守的团体行动有价值，但不会一律拒绝进攻。已知必败的攻击不值得继续交防守资源。 |
| 阴谋与能力 | 搜索准备效果后能否接上有效行动；回合末消失而未利用的强化没有额外分。反制按放行与反制后的局面比较，仍可能因有限搜索和未知手牌而误判。 |
| 资源经营 | 空位和可持续收益提高部署价值；可用行动能转化成手牌时更愿意使用。满手、满场或代价过高会降低投入，不为提高使用次数强行报废替换。 |
| 势力树 | 兼顾忠诚、位置、被动防御、直属光环与上级路径风险。薄弱上级挂大量下属会受罚；深层连接仍可能合理，没有强制浅树或固定长链脚本。 |
| 派系与获胜路线 | 苏黎世偏企业／银行，网络偏计算机，赫尔墨斯偏魔法，UFO偏太空等。各项数量、力量和特殊要求分别计分；持有目标牌时也会争取该路线，临近胜利会更重视补齐短板与阻止敌方达标。 |
| 策略变化 | 同一局每次行动后重新规划，随手牌、公开场面与派系改变。没有为每局指定固定开局套路；相同局面仍可能反复选择同一种高分打法，不能视作具备人类式的风格学习。 |

三档拥有相同的游戏风格、攻防知识和资源估值。简单只能比较单次主要行动后的局面，普通能看到两步配合，困难最多看到四步配合；多步准备仍可能受候选和节点预算限制。战斗／反制都完整预演当前战斗，随后主要阶段重新规划，因此相同局面、相同AI种子的响应可能完全一致。旧策略只保留在`tests/ai_baseline/`供对照测试，游戏难度不会切回旧版。

## 当前找牌扩展

新找牌命令按所选阵营／标签保留不同候选，避免费用组合挤掉其余搜索方向。检索、回收、身份转化等收益仍通过独立信息集规则模型预演；不另写卡牌结算器。公开候选可供双方观察，私密查看仅持有操作权后才进入该玩家观察。付费换候选会比较已知候选和弃牌价值；没有合适替换时可以保留原手牌。

本轮仅做合法性、信息隔离、规划与资源行为回归，没有重新做百局强度对照；先前胜率对应其记录时的卡池。
