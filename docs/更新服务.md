## 仅发布补丁

本轮使用`tools/export_windows.py --pack-only`验证优化PCK及原生EXE，不生成新的完整ZIP。`release_updates.py --patch-only --previous-manifest <上次已发布清单> --baseline <原始0.2.0.pck> --pack <新PCK> ...`沿用已发布完整包的URL、大小与摘要，并保留`full_version`。

使用`deploy_updates.py --patch-only ...`时只上传补丁，服务端先验证保留的完整包及稳定链接确实匹配，再原子切换最新签名清单；不会重传或改写完整ZIP。配套对战服务器仍需导出并部署相同版本。下次发布完整包时继续使用原有完整构建与部署命令。

## 玩家流程

启动后后台检查版本，检查最多等待5秒，不显示阻塞开局的等待窗口。无网、超时或服务器出错时继续离线游戏；不会自动下载。菜单版本按钮及设置中的「检查更新」可手动打开更新窗口，可随时返回游戏，检查或下载仍在后台进行。

下载显示百分比和实际大小，可取消。先下载到临时文件，核对签名、版本、大小和SHA-256后写入待应用记录；当前对局、RNG与运行规则保持不变。未完成的下载不参与启动。

返回主菜单或结束对局后可点「应用更新」。程序自动退出并重新打开，玩家无需手动关开；**规则／AI脚本不是在运行中的对局内热替换**。下次启动在载入游戏脚本前挂载PCK，菜单正常出现后确认启动；若新补丁未能完成启动，下次运行回退到上一份可用补丁或基础包，并阻止自动重试该失败版本。可用`Illuminati.exe -- --safe-mode`跳过缓存补丁和自动检查。

资源、界面和脚本均沿用这个统一流程，避免出现新卡文配旧规则。F5开发模式可检查线上版本，仍使用本地源码运行，不安装玩家补丁。单元测试使用`--test-defaults`禁用自动检查与实际设置读写。

## 服务器

Ubuntu 24.04，Nginx静态文件服务，玩家下载不需要账号或访问密码。公网IP已取得受信任的Let's Encrypt证书，未关闭TLS证书验证。IP证书有效期约6天，由`illuminati-cert-renew.timer`每6小时检查；`certbot renew --dry-run`已验证成功。证书部署后自动重载Nginx。

- 静态根目录：`/srv/illuminati/www`
- 版本文件：`releases/<code>/`
- 最新清单：`windows/latest.json`
- 稳定完整包：`Illuminati-Windows.zip`符号链接
- Nginx配置：`/etc/nginx/sites-available/illuminati-updates`
- 证书：`/etc/letsencrypt/live/illuminati-ip/`
- 临时上传目录：`/srv/illuminati/incoming`，不在公开下载目录下

初始化脚本为`tools/server/setup_update_server.sh`，仅用于新建的专用服务器。正常发布无需重新初始化或重启实例。部署工具通过SSH短暂启用随机PUT专用上传入口，经HTTPS上传、服务器端校验后原子切换版本清单；结束后移除上传入口。下载服务始终为公开只读。

## 构建与发布

发布密钥与服务器SSH密钥是两个独立密钥。SSH密钥由用户提供；发布签名私钥保存在本机`~/.ssh/illuminati-release-signing.pem`，不进入项目、游戏或服务器下载目录。`data/update_channel.json`只含公钥及服务器地址；换电脑发布时需由所有者另行迁移私钥。

1. 检查卡牌表、英文文本，完成本次改动对应的回归。不要覆盖用户总表中的未同步修改。
2. 修改`data/release.json`的版本和严格递增的`code`。普通补丁保持`base_id`及引擎版本不变。
3. 使用`tools/export_windows.py`导出及验证最终优化包。该工具保留原图像素，并包含中文断行所需的TextServer数据；实际Release EXE分别检查中英文。
4. 用`tools/release_updates.py`创建签名清单及累积PCK补丁：

```powershell
python tools/release_updates.py --zip <本版完整ZIP> --pack <本版最终优化PCK> --baseline <该通道最初的最终优化PCK> --key <发布私钥路径> --openssl <openssl程序路径>
python tools/deploy_updates.py --host 47.119.37.251 --key <服务器SSH密钥路径>
```

初次基础版本不传`--baseline`和`--pack`。本通道原始基础PCK为`outputs/windows-0.2.0/Illuminati/Illuminati.pck`，**后续版本另建输出目录，不覆盖它**。

补丁按原始基础包与本版最终优化包的条目实际字节比较，只包含新增、变更及原生删除记录；不重新压缩卡图。它是累积补丁，可跳过中间版本。升级引擎、修改启动器／信任公钥／项目设置或全局脚本类注册表时，构建工具拒绝生成普通补丁，需要建立新基础版本并提供完整包。项目版本展示以`data/release.json`为准，不为每次补丁修改`project.godot`。

发布必须先上传所有文件并校验，再切换`latest.json`。已公开的同一`code`不得更换内容；修复应增加版本号。可先在独立测试路径验证，不将QA清单设成正式最新版本。服务器到期或暂时不可用不影响已安装游戏的离线运行。
