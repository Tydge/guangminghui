# INWO两人局规则核查

核查来源：用户提供的《World Domination Handbook》v1.2（2002年1月），第2、17页。[原始PDF](C:/Users/Oliver/Desktop/game/illuminati说明.pdf)；[官方v1.2规则PDF](https://www.sjgames.com/inwo/rules/inwo-rules-12.pdf)。

第17页说明，两人局容易出现速杀或难以应对的牌组组合，因此以下规则为两人比赛正式规则，也建议用于普通两人局：

| 事项 | 原版v1.2 | 本作当前规则 |
|---|---|---|
| 首轮互攻 | 双方各完成一个完整回合后，才可互相攻击；后手不能首回合突袭先手。 | 保护按各自首回合计算，因此后手首回合可攻击已完成首回合的先手。此次保持原有方式。 |
| 自动接管费用 | 在第3阶段自动接管，会使该回合第4阶段少获得1个本应补充的主牌行动标记。 | 主要阶段通常花主牌1个行动标记；连锁加盟可免该费用，仍每回合限一次。 |
| 新团体行动 | 第2页先自动接管、后补行动标记，新团体会赶上本回合补标记。 | 按用户确认的精简规则：当回合无标记，也不能额外恢复；下次己方回合正常补充。初始手下例外。 |
| 后手补偿 | 开局双方各3张阴谋；两人规则未另给后手额外阴谋。 | 开局双方先各2张；掷骰定先后后，仅给后手额外1张。 |
| 基本团体数胜利 | 基本胜利目标不得少于12个团体。该项指通用基础目标。 | 保留现有主牌特殊目标和消灭对手条件。 |

后手额外1张阴谋及自动接管延后获得行动，是本作采用的平衡调整。当前更严格的“双方首回合均不得互攻”没有被自动加入。所有卡牌的数值和特殊胜利条件仍以完整卡牌表为准。
