# 卡牌重做提案

以下4张仅为提案，尚未实现。总表继续记录游戏实际使用的能力，避免把“重做”等编辑备注显示到卡面。连锁理发店的改名、P3及正统阵营单独按已明确的修改落实；重绘随新能力确认一起完成。

| ID | 卡牌 | 建议能力 | 设计意图 |
|---|---|---|---|
| `G156` | 连锁理发店 | **仪容管理：**该团体的直属名人下属增加正统阵营。 | 理容服务改变公众形象；用于忠诚、阵营修正和支援，不直接堆数值。 |
| `G163` | 农民抗议联盟 | **拖拉机路障：**该团体抵御普通攻击时，位置防御不能被降低或忽略。 | 封路保护自身，抵抗狙击、低空穿行等绕过位置的手段。 |
| `G169` | 合租公寓 | **轮班照应：**该团体支援直属团体上级后，战后可恢复该上级1行动；每回合1次。 | 室友互相分担，形成“支援后接班”的配合。 |
| `E16` | 安全屋（替换便携仓库） | **紧急转移：**己方团体遭普通控制攻击时，可报废本资源，让目标及其下属回手，取消本次攻击。 | 设施／一次性；把组织撤走，避免整支被夺取。 |

仪容管理随直属关系和能力是否有效动态变化，不改印刷阵营。轮班照应沿用恢复通则，直属团体上级不包括光明会；战后仍须由己方控制且满足恢复条件。安全屋不退还双方已支付的费用，不用于普通摧毁或灾难。

用户原始编辑意图：三张团体需重做；连锁理发店另需重绘；便携仓库改为其他资源，不采用暂记的手牌上限+2。这些内容在确认前不覆盖当前实现。
