# 卡牌重做提案

以下2张仅为提案，尚未实现。总表继续记录游戏实际使用的能力，避免把“重做”等编辑备注显示到卡面。

| ID | 卡牌 | 建议能力 | 设计意图 |
|---|---|---|---|
| `G163` | 农民抗议联盟 | **拖拉机路障：**该团体抵御普通攻击时，位置防御不能被降低或忽略。 | 封路保护自身，抵抗狙击、低空穿行等绕过位置的手段。 |
| `E16` | 安全屋（替换便携仓库） | **紧急转移：**己方团体遭普通控制攻击时，可报废本资源，让目标及其下属回手，取消本次攻击。 | 设施／一次性；把组织撤走，避免整支被夺取。 |

安全屋不退还双方已支付的费用，不用于普通摧毁或灾难。

便携仓库需改为其他资源，不采用暂记的手牌上限+2。两项提案在确认前不覆盖当前实现。
