# 光明会：当前运行与验证说明

2026-10-20。Godot 4.6.2 / Compatibility / Windows。打开项目的 `project.godot`，等待首次资源导入，按 **F5**；无需导出试玩包或APK。[项目仓库](https://github.com/Tydge/guangminghui)。

## 当前内容

6种光明会、130种团体、50种阴谋，共186种。唯一总表为 `docs/光明会_全部卡牌完整效果_当前版.md`。本次未修改卡牌数值或效果文字，总表与游戏仍为186张、0处差异。已有用户修改保留。

开局从5张团体中选初始手下，至多2次整手重随；AI同样至多2次。后手额外1张阴谋。自动接管和控制进场的团体当回合无行动标记且不能额外恢复；初始手下例外。

## 动画与操作顺序

统一流程：**出牌／能力展示 → 指向目标 → 骰子及结果 → 结果窗口彻底淡出 → 回手／弃牌、控制／摧毁及布局移动完成 → 后续触发逐项展示和结算 → 下一选择或胜利窗口**。只执行当前动作涉及的步骤。

抽弃牌、目标飞行和骰子均由独立规则副本预演；真实对局及RNG在这些展示完成前不变。提交真实动作后，继续等待桌面卡牌进场、离场及布局移动结束，再解锁并进入下一步。逻辑由完成信号推进，不依赖估计动画时长的额外等待。

所有界面动作共用桌面完成检查。街头帮派、跨国石油公司、硅谷、雷军、进场抽牌及电子游戏恢复等收益排入后续触发；已有标签收益同样逐项播放。双方决定胜负的控制／摧毁均先完成桌面效果，待剩余触发结算完毕才显示胜利。减少动态效果保留同一顺序。

| 操作 | 当前行为 |
|---|---|
| 战斗中的目标动画 | 临时隐藏覆盖窗口，卡牌飞向并高亮实际目标；完成后恢复战斗窗口及拖动位置。 |
| 查看战场 | 选择、战斗和预览中的「查看战场」暂时收起窗口，允许平移缩放、切换手牌与查看大卡；对局和AI暂停。 |
| 返回操作窗口 | 恢复同一选择、已选目标、分页和滚动位置；窗口尺寸变化时重新适配，命令保留。 |
| 重开／退出 | 取消展示、桌面等待和窗口过渡，旧对局不能推进新对局。 |
| 分步操作 | 重组等依次选择团体、上级、费用；可返回或取消，确认前不支付。 |
| 卡牌查看 | 开局图片点击只查看；附着按钮可阅读完整效果并返回原团体与阅读位置。 |
| 小卡可读性 | 场上138×192、手牌94×142；数值及阵营分别使用12号／11号深色字，按完整文字行绘制。 |

## 素材与跨电脑开发

全部186张卡图和4张界面素材随仓库提供，190张运行图像合计213,148,664字节，以WebP保存。卡图和大小卡图片区均为1:1，等比完整显示，不拉伸。G084和G089使用用户提供的真人照片：G084保留615×615原构图；G089选取1078×1078构图保留完整头部、上半身、10号和袖标，均无损转换。原件位于 `assets/sources/`，不导入Godot；作者及许可未提供，未标作开放许可。生成提示词、来源及处理记录保留在 `docs/art-prompts.json`、`docs/asset-audit.json`、`docs/image-compression.json`。

音效Kenney Interface Sounds（CC0），字体Noto Sans SC（OFL），许可随项目提供。仓库排除 `.godot/`、本机阅读路径配置、临时报告与截图；克隆后Godot自动重建缓存。新电脑的卡牌同步工具默认读取项目内总表，不依赖原电脑绝对路径。
