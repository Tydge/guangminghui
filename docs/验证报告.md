# 光明会：当前运行与验证说明

2026-10-22更新。Godot 4.6.2 / Compatibility / Windows。打开 `project.godot`，等待资源导入后按F5运行；无需导出试玩包或APK。

## 当前内容

8张光明会、150张团体、60张阴谋、15张资源，共233张。运行数据、两份共同维护总表、阵营与标签统计保持同步，0字段差异；插画未改动。

民调利好仅防普通控制／摧毁；云服务商的弹性扩容可用于灾难防守，先按资格采用P或GP并翻倍，其他加值不翻倍，费用照付。灾难进攻方仍不能提供普通支援。澳大利亚只替换部署费用，部署仍占用与自动接管共用的每回合一次机会，确认窗口已补充提示。

反制询问的「查看战场」移到反制／放行决定旁，可用Esc收起与恢复。查看期间保留原窗口和待结算阴谋，允许阅读战场、手牌，禁止规则与AI推进，不付款、不消耗RNG。

总表改动同时落实：麦迪逊大道GP+3、地下报刊对政府控制防御+4、奥特曼企业／怪异、奥巴马P4、拉斯维加斯5–6才抽3张阴谋。瑞士经确认仅普通摧毁用R，灾难改用有效P；大卡分别显示两种基础防御，帮助和英文卡文同步。

设置中的「语言 / Language」可选择中文和English，立即刷新并保存。覆盖卡牌名称与效果、目标和费用、菜单、帮助、开局、图鉴、分步选择、攻击预览、战斗记录、动效字幕和胜利窗口。翻译只在显示层执行，中文规则标签、合法命令与日志原文保持不变。

英文大小卡保持1:1插画比例，元数据可换行，小卡的数值及阵营行完整显示。英文阵营在小卡使用紧凑缩写，查看完整卡牌显示全称。长标题、固定区域正文及胜利窗口适配英文宽度；详情正文保持滚动阅读。切换语言保留真实对局、RNG、已选目标、待选步骤和附着阅读历史，关闭设置后恢复当前窗口。

英文基础说明位于 `docs/Quick_Start_EN.md`，包含开局、回合、资源、P／GP／R、10个阵营的含义和对立、标签、忠诚、位置、自卫、支援、灾难和胜利。游戏内新增「阵营与标签」帮助页。

## 后续维护

运行 `tests/run_checks.ps1` 可执行完整回归，包括英文整局。测试进程使用独立设置或 `--test-defaults`，不读取、修改玩家实际语言偏好。

卡文或卡名改变后，核对 `data/localization/en.json` 中译文与来源快照，运行 `python tools/check_localization.py` 检查遗漏、过期文字、显示词汇及占位符。游戏卡牌总表仍由 `tools/card_table.py` 维护；英文目录不参与规则计算。

完整卡牌以唯一当前版总表为准。所有233张卡图继续使用现有1:1压缩素材，既有许可与来源见素材记录。
