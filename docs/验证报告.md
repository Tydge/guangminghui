# 光明会：当前运行与验证说明

2026-10-20。Godot 4.6.2 / Compatibility / Windows。打开项目的 `project.godot`，等待首次导入后按 **F5**。本次没有导出试玩包或APK。

## 当前内容

6种光明会、150种团体、50种阴谋，共206种。卡牌数值按用户确认表实现，唯一维护总表为 `docs/光明会_全部卡牌完整效果_当前版.md`。总表及阅读副本包含全部卡牌、通用规则和自动统计，与运行数据0处差异。

本次实现直属共产力量／槽位光环、在场力量强化、费用代付、能力反制、附着转移、占星支援、狂热忠诚、免费停泊、位置下限、战利品、牌堆窥探、免标记自卫、战后护送、孤军破袭、防备扩展、临时阵营和夺取后重建。多参数操作分步选择；费用选项合并入口，不铺开组合长表。

检查了原有全部186张卡牌描述，精简140张效果文字。重复的支援费用、恢复限制、附着生命周期等集中到通用规则；保留独有的对象、费用、时机、次数及例外。槽位失效作为通则，未写入住房合作社卡面。游戏「卡面用语」也可查看。

开局从5张团体手牌选择，双方各最多2次整手重随，后手额外1张阴谋。自动接管和控制进场当回合无标记且不能额外恢复；初始手下例外。

## 动画与状态

出牌／能力展示 → 目标指向 → 骰子与结果 → 窗口完全淡出 → 回手、弃牌、控制或摧毁及布局移动完成 → 战后触发 → 下一选择或胜利。规则副本预演包括RNG，真实状态在前置动画结束前不变。新能力使用同一时序，临时覆盖窗口可收起查看战场。

新状态在大卡显示：直属光环、在场强化、伪造身份、防备的摧毁适用范围及限次效果。占星骰点写入战斗记录；身份模板公开时展示实际卡牌。

补修了战斗及反制按钮单选分支的异步调用问题，已通过实际按钮信号回归。
