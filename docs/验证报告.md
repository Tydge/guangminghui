## 展示与时序

出牌／能力展示 → 目标指向 → 骰子与结果 → 窗口完全淡出 → 卡牌转移及桌面布局完成 → 后续触发 → 下一选择或胜利。规则副本包含RNG，真实状态在前置动效结束后才提交。目标宣告同样先展示来源与反制，再结算普通出牌收益和胜利。

8张主牌按每页4张展示；点卡面查看，点选择按钮确认。目标达标后显示“宣告胜利”，未达标只显示简短进度；完整解释放在大卡中。
