## AI结构评估

长链不是本游戏的通用最优摆法。直属主牌的位置防御为+10，第二层+5，第三层起为0；中间团体被夺取时，其下属整支一起易主。共同阵营的忠诚、直属能力和槽位限制可以使某条链合理，但不能据此无条件一直向下连接。

修正了旧估值中按直属下属数量增加行动价值的奖励。这项奖励会在没有实际能力收益时仍鼓励嵌套。新的 `ai_structure.gd` 从规则引擎读取有效抗性、忠诚、位置和被动控制防御，按路径的薄弱环节折算下属风险；候选筛选也考虑摆放质量，避免提前漏掉合适上级。该指标是启发式分值，不是准确被控制概率，也不强制所有团体浅层摆放。

定向场景确认：有合适主牌空槽时采用受保护的浅层位置；同阵营忠诚、高档沙龙的名人加成和合租公寓的五阵营门槛可以使嵌套更优。未为这两张新能力另加卡牌专用AI规则。

简单难度使用带随机性的即时估值；普通最多搜索2个己方主要行动，困难最多3个。交替响应、反制、选择与战斗由同一规则引擎预演。两个信息集样本来自未见卡池，不接收真实敌方隐藏手牌、牌堆顺序或真实RNG。搜索运行于线程独有的Agent和规则模型，界面可暂停、恢复及重开取消。结构试放只操作规划器私有节点，完整还原，不触发进场或推进随机数。

## 对局测试

结构修正前先跑48场：3组难度配对，每组8个派系种子，每个种子交换双方难度各打一场。双方使用同派系以减少派系匹配偏差，指令上限为1000；每步检查合法动作、卡牌守恒及AI不修改真实RNG。

| 配对 | 修正前16场 |
|---|---|
| 困难／普通 | 9／7 |
| 普通／简单 | 9／7 |
| 困难／简单 | 10／5，另1场达到指令上限 |

达到上限的一场为种子805、UFO镜像，双方各25个回合；不是平局或已结束对局。这批胜负说明难度差距仍不稳定，不能声称困难已稳定压制普通。

结构修正后，在其中4个相同派系种子（801、803、805、807；巴伐利亚光明会、克苏鲁仆从、UFO、红色议会）上再跑24场，同样交换难度。新报告的数据及AI核心文件哈希均匹配当前代码，不能与前48场混作同一版本胜率。

| 配对 | 同4种子修正前8场 | 修正后8场 |
|---|---|---|
| 困难／普通 | 3／5 | 6／2 |
| 普通／简单 | 7／1 | 6／2 |
| 困难／简单 | 5／2，1场超限 | 6／1，1场超限 |

修正后共7519次规则指令，23场正常结束；红色议会镜像种子807的一场在双方各28回合时达到1000指令上限，不能当作困难获胜。最后困难方有29张团体、3条主牌分支、最大深度5；简单方11张、2条分支、最大深度3。这也说明结构合理不等于能可靠收束所有长局。样本只有每组4个配对种子，结果有改善迹象，但不能证明稳定胜率或策略最优。

只取在场至少4张团体的回合末记录：困难共170次，主牌直属分支平均2.98条，树的最大深度平均2.90层，未出现整棵树为单链的记录；局部最深仍有5层。普通177次的平均分支为2.99条、最大深度平均2.79层。这些回合末记录互不独立，只用于检查摆放行为，不作为统计显著性样本。

修正后的困难AI使用过50个不同带头卡牌ID，并有招募、夺取、摧毁、阴谋、能力、资源及调整结构等不同动作；不会仅执行一套固定出牌顺序。不过普通和困难仍明显偏向稳妥扩张，现有2／3步搜索也未完整预判对手下一回合。

同一手牌在巴伐利亚、网络、UFO下会分别优先招募中国、电信公司、美国航天局，说明选牌会响应目标。相同公开局面下，地方警察／街头帮派的12个种子测试在普通和困难均选择地方警察；两牌P／GP相同，但抗性、阵营及能力不同，因此这并不是严格同分的随机性测试。重复选择可以是稳定优选，不能单凭重复判定固定脚本。当前最终同分仍按候选顺序选择，测试也不能保证所有局面都足够多样。

样本中首个主要行动均为自动接管。每回合无掷骰扩张通常是合理开局选择；是否存在固定策略需结合后续攻击对象、支援、出牌及树形判断。记录到的少量同回合重复命令主要为普通攻击重试；合法性检查通过并不代表每次重试都是最优。行动追踪只保存每局前160个主要行动，不据此保证没有任何无效操作。
