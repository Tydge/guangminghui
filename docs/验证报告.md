## 交互修复

| 操作 | 当前行为 |
|---|---|
| 图鉴分类 | 当前页至多两行，插画异步加载并预读下一页，避免一次构建130张团体卡。原生渲染本次分类面板构建耗时：光明会约67ms、团体约2ms、阴谋约2ms；此为本机面板构建采样，并非所有设备完整加载时长。 |
| 卡面文字 | 按完整字行及字体高度排版；标签占用独立完整行，正文只绘制放得下的完整行。小卡可省略，完整效果通过大卡查看。图片区仍为1:1完整显示。 |
| 重组及多参数动作 | 按团体、上级、费用逐步选择；高亮合法场上目标，可返回、取消或分页列出。确认前不支付行动或弃牌。战斗的同卡不同参数响应也合并后再选。 |
| 摸牌／弃牌 | 卡牌从对应来源移动到手牌或弃牌堆，同批依次错开。未知牌仅用牌背，不显示AI隐藏牌名。 |
| 附着牌查看 | 团体大卡提供附着牌按钮，打开完整效果和费用；关闭返回原团体，保留阅读滚动位置。 |
| 指定目标的阴谋 | 卡牌展示后飞向实际目标并高亮，必要时平滑移动镜头。等待反制时不提前作用，被反制后不播放生效目标动画。 |
| 开局查看与选择 | 光明会和初始团体卡面点击仅查看，明确的「选择」按钮才确认。 |

抽弃牌和目标动画使用独立规则副本预演；真实手牌、牌堆、费用、场面及RNG在全部动效结束前保持不变，之后执行一次真实动作。动画期间输入和AI锁定，重开取消待执行动作。保留中央技能展示、反制时机、减少动态效果、攻击窗口拖动、树桌面平移缩放及长按查看。
